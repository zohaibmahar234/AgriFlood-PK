# Historical demo walkthrough
1. Start the app and choose **Historical replay (2022)**.
2. The replay loads `data/reference/unosat_2022_khairpur.json`.
3. It displays verified public source dates/statistics and the rationale for Khairpur selection.
4. It does **not** draw an invented flood polygon.
5. Configure Earth Engine and use **Scientific jobs** to generate the actual Sentinel-derived flood summary.
