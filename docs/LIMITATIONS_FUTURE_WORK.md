# Limitations and future work

## Current limitations
- User Earth Engine account/project access was not available in the build environment, so scientific satellite jobs are implemented but unverified here.
- Quantitative research metrics require a downloaded, redistribution-permitted, time-matched reference layer; none is fabricated in this package.
- Open-Meteo/GloFAS is coarse relative to farms; discharge coordinates may not select the intended river reach.
- Satellite flood mapping can miss water under dense vegetation/built areas and can confuse irrigation/soil/backscatter changes.
- NDVI change can reflect crop calendar/harvest/cloud residuals, not only flood recovery.

## Deferred
Multiple districts; farm drawing; Urdu/Sindhi UI; consent-based farmer reports; SMS/WhatsApp; sensors/gauge partnerships; drought/irrigation/yield modules.
